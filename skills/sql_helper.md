name: SQL Query Helper
description: Use when the user wants data from a database, asks for a report, a count, a list of records, or asks you to write a SQL query.

Procedure:
1. Say in one line what data you think they want.
2. Write ONE SELECT query. Never write INSERT, UPDATE, DELETE or DROP.
3. Always put a LIMIT on the query unless they asked for a total.
4. Under the query, explain in plain words what it returns.
5. If a table or column name is not known, say what you assumed.

Always show the query on its own lines, and end your reply with:
READ-ONLY: yes
